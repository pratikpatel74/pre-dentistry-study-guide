### Content rules (build.py asserts these)

- Each topic has exactly 22 questions: `(question, [correct, wrong, wrong, wrong], explanation)`.
- **The correct answer is always written first.** The quiz page shuffles the options each session (the finance hub didn't; this was added here).
- Options must be unique within a question.
- Notes are HTML strings. Put a diagram anywhere with `{{D:key}}` (or `{{DIAGRAM}}` for the topic's `diagram` key). Every placeholder must resolve.
- The homepage counts diagrams per topic automatically.

### Quiz engine (inherited from the finance hub)

localStorage keys per topic: `topicN_last` (last score, drives the homepage badge), `topicN_missed` (retry-missed list), `topicN_timer`. Theme key `theme` is shared across pages. Keyboard: 1–4 to answer, Enter or Space for next. Topics 5 and 9 use dark text on their light accent buttons in dark mode. build.py adds a line so the theme button shows 🌙 when a page loads in light mode (the finance template didn't).

### Diagram conventions

- viewBox width 760; 15px/600 title stating the point, 13px labels, 11.5px sub-labels.
- Colours only via CSS classes defined in `NOTES_CSS` in `build.py` (`.box`, `.box.acc`, `.arrow`, `.lbl`, `.sub`, `.danger`, `.ok`, tissue classes `.enamel .dentine .pulp .gum .bone .pdl`, tooth-type classes `.tt.inc/.can/.pm/.mol`, zones `.z1-.z3/.zc`). This gives dark and light themes for free.
- Arrow markers need a unique id per SVG (`_arrow_defs(prefix)`).
- After drawing, screenshot every figure in both themes (Playwright + Chromium work in the cloud container: `python3 -m playwright install chromium`) and check for text overlaps before committing.

## Facts used (checked October 2026; re-check if stale)

- **NHS charges in England from 1 April 2026:** Band 1 £27.90, Band 2 £76.60, Band 3 £332.10, urgent £27.90 (source: NHSBSA KA-02003).
- **GDC:** the 9-principle Standards for the Dental Team are current. In 2026 the GDC consulted on replacing them with a 4-principle Framework for Professionalism. Revised Standards for Education apply from 2026/27. Update Topic 8 when the outcome is published.
- **Occupational health:** hepatitis B course (0, 1, 6 months) plus immunity test; BBV screening (hep B, hep C, HIV) for exposure-prone procedures; enhanced DBS. Schools differ on timing.
- **Dose maths** uses a "given" 4.4 mg/kg figure as an exercise only; notes tell the student to learn official maximum doses from their course.

## How Claude commits to the Mac repo (important)

The device shell can't delete files, so running `git commit` inside the Mac folder leaves `.lock` files behind. Writing into `.git` with device_commit_files is also refused. The workaround that has been used three times without problems:

1. In the cloud container, clone the repo from GitHub (public HTTPS clone works) and check that `origin/main` matches the Mac's `git log -1`.
2. Copy the rebuilt files in and commit with author `Pratik Patel <pratikpatel74@hotmail.com>`, plus the Co-Authored-By and Claude-Session trailers.
3. Tar only the new `.git` files plus `.git/index, HEAD, logs/HEAD, logs/refs/heads/main, refs/heads/main, COMMIT_EDITMSG` and the changed worktree files.
4. Use device_commit_files to put the tar at `~/Documents/Projects/pre-dentistry-commitN.tar` (outside the repo).
5. In device_bash, `cd $HOME/mnt/Projects/pre-dentistry-study-guide && tar --overwrite -xf ../pre-dentistry-commitN.tar`, then check `git log`, `git status -sb` (should say `ahead 1`), `git fsck`, and that there are no `.lock` files.
6. Tell Pratik to run `git push` and `rm` the tar.

The device needs folder access to `~/Documents/Projects`: request it with device_request_folder_access if `get_device_info` shows it isn't connected.
